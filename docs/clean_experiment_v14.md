# DeepBrain v1.4: изолированный эксперимент и часы привычек

HabitPersistenceSnapshot schemaVersion=3 хранит ClockTick — монотонное
симуляционное время привычек. LastCueTick и LastExecutionTick имеют ту же шкалу,
а не шкалу текущего запуска Host. Время выключенного процесса не учитывается.
ClockTick продвигается и во сне; Flush сохраняет его без новых подкреплений.
API system/status показывает «часы привычек». Старое имя habits.v2.json допустимо:
формат определяется schemaVersion внутри файла.

При чтении v2 достоверный возраст неизвестен: старые файлы могли содержать тики
нескольких запусков. Миграция сохраняет силы, счётчики и награды, обнуляет только
две временные метки и даёт полный период до затухания. Она не делает старый опыт
проверенным. Чистый эксперимент вообще не читает старые привычки.

ML/DeepBrain.Experiments — консольный эксперимент на настоящем LifeLoop и
BrainMlService. Запросы проходят сериализацию DTO DeepBrain и десериализацию DTO
ML.Host. TCP, API и Ollama не запускаются. Вызов TickOnce через reflection
используется только здесь для ускоренного воспроизведения симуляционного времени.
Конструктор LifeLoop допускает внедрение IMlPolicyAdvisor; обычный Host сохраняет
свой прежний способ создания backend.

Запуск: dotnet run --project DeepBrain.Experiments -c Release -- CONFIG NEW-DIR
[TRAIN-TICKS=24000] [EVAL-TICKS=2400]. NEW-DIR должен отсутствовать.

Обучение начинает с новой сети seed=1337, пустого replay buffer и отдельных файлов
эпизодов/опыта/привычек. ImportPath пуст. Используются параметры исходной конфигурации,
но backend в эксперименте реализован внутри процесса. LearningRate требуется 0.0005:
именно эту величину использует текущая реализация удалённого ML.Host.

Сравнение выполняется на каждом сценарии для world seed 1337, 2027 и 4099.
Каждая пара начинается новым LifeLoop с одинаковыми начальными параметрами,
сценарием и seed среды. Действия могут менять дальнейшую среду; это не обещание
одинаковых последовательностей событий после разных действий.

В обеих ветках сравнения выключены долговременная память, привычки и LLM.
Кратковременные механизмы агента работают в обеих ветках. В обученной ветке
заморожена сеть, epsilon=0, влияние сети=NetWeightMax исходного конфига
(обычно 0.6), warmup=1: проверяем эффект обученной сети при рабочем весе.
Это смесь сети с эвристикой, а не чистая нейросеть. Вторая ветка использует эвристику.
Число вызовов обучения в evaluation должно быть нулевым; контрольная сумма
обученного файла весов должна оставаться прежней.

metrics.jsonl содержит выборки каждые 200 тиков; result.json — агрегаты всех тиков;
report.json — пары и разности суммарных наград. Сумма включает нулевую награду сна.
maxAbsQ — максимум по всем выходам сети, включая запрещённые действия, не метрика
выбранного действия. Числа Q и loss сами по себе не доказывают качество поведения.
DONE означает завершение процедуры, а не разрешение на выпуск модели.
24000 тиков — пилот. Он не доказывает сходимость и не заменяет длительную проверку.

Все веса и результаты лежат под NEW-DIR. Сервисные метаданные имеют суффикс
.service, веса — .service.net, а metadata advisor — отдельный файл checkpoint.
Исходный обученный checkpoint никогда не перезаписывается оценочными прогонами.
Перенос модели обратно в рабочий Host в этой процедуре не производится.
