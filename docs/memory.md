# Долговременная память DeepBrain

## Назначение

Версия 1.1.0 добавляет первый постоянный слой памяти: DeepBrain помнит завершённые эпизоды после перезапуска и использует похожий прошлый опыт при выборе действий. Этот слой не зависит от ML backend, LLM или внешней базы данных.

Кратковременные `EpisodeMemory` и `SemanticMemory` продолжают работать в RAM. `PersistentEpisodicMemory` дополняет их, а не заменяет.

## Что сохраняется

Одна строка `memory/episodes.jsonl` соответствует одному завершённому эпизоду и содержит:

- идентификатор, сценарий и время;
- длительность и причину завершения;
- среднюю и суммарную награду;
- гистограмму действий и доминирующее настроение;
- средние боль, безопасность и возбуждение;
- количество петель и итог оценки сценария;
- вычисленную значимость воспоминания.

Эпизоды короче `minEpisodeSteps` не сохраняются, чтобы ручные технические сбросы не засоряли память.

## Вспоминание

Контекст текущего состояния сравнивается с сохранёнными эпизодами по трём группам признаков:

- близость боли, безопасности и возбуждения — 55%;
- совпадение сценария — 30%;
- совпадение доминирующего настроения — 15%.

Результат умножается на значимость и коэффициент давности. Период полураспада задаётся `recencyHalfLifeDays`.

Успешные действия получают небольшой положительный сдвиг оценки, неуспешные и связанные с петлями — отрицательный. Абсолютное влияние ограничено `maxActionBias`. Память применяется только к кандидатам, уже разрешённым логикой и маской действий.

## Конфигурация

```json
"memory": {
  "enable": true,
  "path": "memory/episodes.jsonl",
  "maxEpisodes": 5000,
  "recallTopK": 8,
  "minSimilarity": 0.45,
  "maxActionBias": 0.15,
  "recencyHalfLifeDays": 90,
  "minEpisodesBeforeBias": 3,
  "minEpisodeSteps": 25,
  "rewardScale": 0.02
}
```

Если секции нет в старой конфигурации, используются эти безопасные значения по умолчанию.

## Команды

- `memory.status` — состояние, размер, путь, последний поиск и ошибки;
- `memory.recent [count]` — последние воспоминания;
- `memory.search <query>` — поиск по сценарию, настроению, причине завершения или действию.

## Надёжность

- повреждённая JSONL-строка пропускается и отражается в `memory.status`;
- объём RAM ограничен `maxEpisodes`;
- при разрастании файла выполняется атомарное уплотнение через временный файл;
- ошибки чтения и записи не останавливают `LifeLoop`;
- каталог `memory/` исключён из Git.

## Следующие уровни

После стабилизации эпизодического слоя можно добавить:

1. постоянную семантическую память — факты и устойчивые закономерности;
2. консолидацию во сне из эпизодов в знания;
3. управляемое забывание и разрешение противоречий;
4. векторный поиск и текстовое осмысление через LLM как необязательный верхний слой.
