# Contextual appraisal — DeepBrain 1.12 / Web 0.17

Qwen evaluates new conversation observations after the conversational reply finishes. It receives the complete current user message and up to four complete preceding user/assistant pairs from the same conversation, at most two hours old. Forgotten/excluded context and internal voice-delivery commands are omitted. Existing history, facts and past appraisals are never reinterpreted or replaced during upgrade.

The model classifies intended meaning, possible irony, confidence and ambiguity. The desktop 9B model also supplies a short contextual explanation and target; server 4B uses a smaller categorical response and an application-written explanation to reduce CPU generation time. Irony is an uncertain interpretation of text, not a measurement of vocal intonation; Alice provides recognized text. Sarcasm, mixed feelings and missing context can still be misread. Confidence is a model estimate, not a calibrated probability.

The worker is independent of reply generation and voice delivery. New foreground dialogue cancels the active background HTTP inference and retries the appraisal later. Desktop is preferred, with the existing server 4B fallback. No OpenAI/cloud call is introduced. If unavailable, incomplete, oversized or invalid, the observation is retained with an uncertain appraisal and has no new emotional effect. Historical/stale inputs keep the previous no-current-emotion behavior.

Ollama structured JSON outputs are used according to its [official API documentation](https://github.com/ollama/ollama/blob/main/docs/api.md). Output validation still enforces a closed schema, categories, finite confidence and response bounds. Raw model explanations remain Web audit data, escaped for display; they are never core instructions, factual memories, commands, or rewards.

Core accepts optional semantic metadata in journal schema 2. Appraisal kind maps to fixed bounded emotional contributions; Qwen cannot choose arbitrary intensities or actions. Ambiguous, unavailable or confidence below 0.6 means no new emotional influence. Otherwise confidence scales the existing limits, and possible irony lowers influence further. Existing bodily priorities, gradual decay and action masks remain in place.

The complete appraisal and outgoing observation are frozen in the additive `conversation_appraisals` SQLite table before delivery. Lost acknowledgments and restarts reuse exactly the same payload without repeating inference or applying twice. Prior request rows and original memory files are untouched. Optional semantic fields are omitted when null, preserving all legacy journal digests and runtime schema-3 hashes byte-for-byte. Remaining influence and semantic metadata survive full runtime restoration.
