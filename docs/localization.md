# Русская локализация

## Область действия

Русский язык используется во всём тексте, предназначенном для человека:

- интерфейсе DeepBrain.Studio;
- консольной панели и командных ответах DeepBrain.Host;
- журналах, компактной трассировке и сообщениях об ошибках;
- документации и инструкциях.

## Что остаётся английским

Для обратной совместимости не переводятся:

- имена классов, методов, файлов и каталогов;
- JSON-поля и DTO;
- типы сообщений TCP-протокола из `Msg`;
- имена команд (`mlstatus`, `scenario.set` и другие);
- стабильные внутренние коды действий, состояний, сценариев и причин.

Studio и консоль преобразуют стабильные коды в русский текст только при отображении. Поэтому Host, Studio, ML.Host и сохранённые отчёты продолжают использовать один и тот же машинный контракт.

## Словарь отображения

Общие переводы находятся в `DeepBrain.Shared/Localization/RussianDisplay.cs`.

При добавлении нового внутреннего значения:

1. не изменяйте машинный идентификатор;
2. добавьте перевод в `RussianDisplay`;
3. используйте `RussianDisplay.Token(...)` только на границе отображения;
4. добавьте проверку в `RussianDisplayTests` для важного нового значения.

Неизвестные идентификаторы намеренно отображаются без изменений. Это позволяет диагностировать новые значения и не подменяет их ошибочным переводом.
