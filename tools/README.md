# Сопровождающие исходники

`windows/qwen_supervisor.py` — действующий алгоритм автозапуска Ollama и обратного SSH-туннеля. Для публикации адрес сервера вынесен в `DEEPBRAIN_SSH_TARGET` (`user@host`), порт — в `DEEPBRAIN_SSH_PORT` (по умолчанию 28534), файл проверенных ключей сервера — в `DEEPBRAIN_KNOWN_HOSTS` (по умолчанию `~/.ssh/known_hosts`). Отдельный пользовательский ключ `~/.ssh/deepbrain-qwen-tunnel` должен быть создан и ограничен на сервере заранее. Ключей в репозитории нет. Эти переменные должны быть доступны процессу при входе в Windows.

Остальные Windows-скрипты сохраняют проверенный путь установки Ollama 0.40.16 и загрузки конкретной модели. Они зависят от подготовленного каталога `%LOCALAPPDATA%/DeepBrain/downloads` и официального файла контрольных сумм. Это сопровождающие скрипты конкретной установки, а не универсальный установщик.

`linux/resume_existing.py` — запуск **уже существующей** обученной эпохи с резервной копией и восстановлением контрольной точки. Требует `DEEPBRAIN_EPOCH`; дополнительно поддерживает `DEEPBRAIN_RUNTIME_DIR` и `DEEPBRAIN_WEB_START`. Ожидает структуру каталогов версий и `brainconfig-production.json`, совпадающий с данной эпохой. Не предназначен для пустой новой установки и не переносит конфигурацию сам. Полные конфигурации, снимки памяти, веса и переписку храните отдельно от Git.

Новый экземпляр ядра запускайте по [инструкции Linux](../docs/linux_run.md). При переносе действующего экземпляра сначала перенесите резервную копию всех данных и согласуйте абсолютные пути; не создавайте новую память вместо прежней.
