# DeepBrain 1.12 — Глубокий разум

Локальный исследовательский агент с памятью, обучением, моделируемыми эмоциями, целями и планированием. «Глубокий разум» общается через Web и Яндекс Станцию; Qwen оценивает смысл реплик и возможную иронию. Эмоциональные состояния — вычислительная модель, а не утверждение о человеческих переживаниях.

## Исходники

| Каталог | Содержимое |
| --- | --- |
| `src/` | .NET-ядро, общие протоколы, настольная Studio |
| `tests/` | Проверки когнитивных функций и восстановления |
| `web/` | Web 0.17.1, диалог, память беседы, Алиса, Станция, эмоции |
| `tools/` | Скрипты запуска Linux и локальной Qwen на Windows |
| `docs/` | Архитектура и документация функций |

ML.Host, обучение и сохранение replay-буфера находятся в отдельном репозитории [ML, совместимая ветка 1.12](https://github.com/isuhanov15-droid/ML/tree/DeepBrain-v1.12.0-release). В этой публикации сохранена история разработки ядра с версии 1.4 до 1.12. Актуальная ветка: `DeepBrain-v1.12.0-release`.

## Возможности текущей версии

- Связь внутреннего голоса с выбором действий; цели, проверка результата и обучение стратегиям.
- Рабочая память, эмоциональный спектр, отложенные намерения и прогноз последовательностей действий.
- Полное восстановление состояния ядра, текущего сценария и незавершённого плана; сохранение обучающего буфера в ML.
- Общая переписка Web и Станции, запоминаемые факты, «Глубокий разум» как голосовой собеседник, автоматическое озвучивание и отображение настроения.
- Qwen 9B на компьютере с резервом 4B на сервере; смысловая оценка эмоций и иронии. При неоднозначности новое эмоциональное влияние не применяется.

## Сборка и проверка

Нужны .NET SDK 8+, Python 3.11+. Linux-запуск использует tmux. Web и ML — отдельные процессы.

```bash
dotnet build DeepBrain.sln
dotnet test tests/DeepBrain.Tests/DeepBrain.Tests.csproj -c Release
cd web
python3 -m unittest discover -p 'test_*.py' -q
```

Начните с [запуска Linux](docs/linux_run.md), [Web](web/README.md), [восстановления состояния](docs/runtime-continuity.md) и [оценки смысла](docs/semantic-appraisal.md). Базовая `brainconfig.json` — пример; включение функций и пути хранения задаются конфигурацией вашей установки.

## Данные действующего агента

В Git входят код, тесты и документация. Переписка, личные факты, опыт, контрольные точки, веса моделей, пароли, токены, секретный адрес навыка и конфигурация устройств хранятся отдельно. Публикация исходников не является резервной копией этих данных. До обновления работающего экземпляра сохраняйте все его каталоги данных; не откатывайте базы поверх новых разговоров.

Голосовой ввод и синтез выполняет Алиса; ответы Qwen формируются локально. Семантическая оценка использует распознанный текст и контекст, не интонацию. Подключение локального протокола Станции неофициальное и зависит от совместимости устройства. [Подробнее](web/STATION.md).
