# DeepBrain Web 0.17 — Лада

Web-панель DeepBrain 1.12, общая переписка Web и Яндекс Станции, долговременные факты, автоматическое озвучивание и отображение эмоций. Qwen 9B на компьютере автоматически заменяется серверной 4B, когда компьютер недоступен. Новый фоновый разбор оценивает смысл и возможную иронию; неоднозначная оценка сохраняется без нового эмоционального влияния.

## Проверка

```bash
python3 -m unittest discover -p 'test_*.py' -q
```

Основной сервер использует стандартную библиотеку Python. Для Станции и QR-кода установите зависимости из `requirements-station.txt` в отдельное окружение либо в каталог `station-output-deps`, используемый адаптерами. Для исполнения нужны Python 3.11+ и tmux на Linux; тесты также работают на Windows.

## Установка и данные

`python3 install.py /home/ivan/deepbrain-web-01` обновляет **существующую** установку, сверяет `manifest.json`, сохраняет прежний код и перезапускает только Web. Для первой установки скопируйте исходники в отдельный каталог, подготовьте локальное ядро и запустите `start.py`. Скрипты настроены на Linux-каталоги `/home/ivan/`; для другой учётной записи их нужно адаптировать до запуска.

Пароль, настройки, `history.sqlite3`, `dialogue.sqlite3` и `alice.sqlite3` находятся вне исходников, в `/home/ivan/deepbrain-web-data`. Память и контрольные точки ядра хранятся отдельно. Перед обновлением сохраняйте обе группы данных; не заменяйте их пустыми файлами или примерами из репозитория.

### Параметры входа в Яндекс

Опубликованная версия читает `DEEPBRAIN_YANDEX_CLIENT_ID` и `DEEPBRAIN_YANDEX_CLIENT_SECRET` из окружения. Используйте параметры клиента, имеющего необходимые права доступа к вашему устройству. Обычный произвольный OAuth-клиент не обязательно имеет доступ к Glagol. Без этих параметров новый вход сообщает `invalid_client`; уже сохранённый токен Станции продолжает работать. Не добавляйте значения в Git.

Устаревший диагностический QR-помощник дополнительно требует `DEEPBRAIN_YANDEX_PASSPORT_CLIENT_ID` и `DEEPBRAIN_YANDEX_PASSPORT_CLIENT_SECRET`. Web использует вход по короткому коду, а не этот помощник. Секреты приложений и пользовательские токены в исходники не включены.

При изменении устанавливаемых файлов обновите манифест командой `python3 tools/build_web_manifest.py web` из корня репозитория.
