# Локальный диалог Qwen

> Ниже описана первоначальная установка Web 0.10. Актуальное автоматическое переключение Web 0.11 описано в [FAILOVER.md](FAILOVER.md) и заменяет прежнее поведение при недоступности компьютера.

Web 0.10 поддерживает Qwen на Windows через Ollama. Ядро DeepBrain, его внутренний голос, память и обучение продолжают работать на Ubuntu. Переписка хранится отдельно в `deepbrain-web-data/dialogue.sqlite3`; при обновлении прежние строки и номер беседы сохраняются.

## Подключение

- Windows: Ollama 0.40.16, `qwen3.5:9b-q4_K_M`, контекст 16384, до 1024 выходных токенов, без отдельного вывода рассуждений.
- Ollama слушает только `127.0.0.1:11434`, облачные возможности отключены через `OLLAMA_NO_CLOUD=1`.
- Исходящий SSH-туннель передаёт серверный `127.0.0.1:11435` на Windows `127.0.0.1:11434`. Сетевые порты Ollama не открываются.
- Отдельный ключ `~/.ssh/deepbrain-qwen-tunnel` разрешает только этот серверный порт, только с IP `10.10.10.91`. Команды, терминал, перенос файлов, агент и X11 запрещены. Локальные перенаправления ограничены неиспользуемым портом 1 на loopback сервера. Временный ключ обслуживания не используется для работы диалога.
- Вход в Windows запускает `%LOCALAPPDATA%\DeepBrain\qwen_supervisor.py` через ярлык автозагрузки. Он перезапускает Ollama и туннель при сбое. Компьютер должен быть включён; запуск до входа пользователя не настраивается.
- Журналы и состояние находятся в `%LOCALAPPDATA%\DeepBrain\logs` и `qwen-status.json`. Создание файла `qwen-stop` в этом каталоге останавливает управляемые процессы. Повторный запуск ярлыка снова включает подключение.

Серверный файл `/home/ivan/deepbrain-web-data/dialogue.json`:

```json
{"provider":"ollama","model":"qwen3.5:9b-q4_K_M"}
```

Проверка доступности раз в пять секунд читает только список моделей. Генерация запускается по явной отправке сообщения. Отключение компьютера не переключает диалог на OpenAI. До шести недавних пар сообщений и небольшой снимок агента передаются Qwen; полные журналы памяти не отправляются. Один запрос обрабатывается за раз, тайм-аут — 120 секунд. Повтор с прежним идентификатором возвращает сохранённый результат. После перезапуска незавершённый запрос помечается прерванным и не повторяется.

## OpenAI позже

Ключ `/home/ivan/.config/deepbrain/openai-api-key` и прежние настройки `openai.json` сохраняются. Для явного возврата установить в `dialogue.json` только `{"provider":"openai"}`. При локальном режиме запросы к OpenAI не отправляются. Старые записи переписки сохраняют название исходной модели и провайдера.

## Откат

Обновление создаёт резервную копию Web, обеих SQLite-баз и прежних настроек диалога в `/home/ivan/deepbrain-runtime/upgrades/local-qwen-*`. Обновляется и перезапускается только Web. Новое поле `provider` в SQLite обратно совместимо со старым Web. Возврат старого Web сам по себе вернёт его старое поведение OpenAI; до возврата при необходимости отключить диалог через `openai.json`.

Для отключения автозапуска удалить ярлык `DeepBrain Qwen.lnk` из папки автозагрузки пользователя и остановить supervisor через `qwen-stop`. Ключ туннеля можно отозвать удалением только строки с комментарием `deepbrain-qwen-local-tunnel` из серверного `authorized_keys`. Весов модели и накопленной переписки это не касается.

Источники: [Ollama для Windows](https://docs.ollama.com/windows), [локальный API](https://docs.ollama.com/api/chat), [модель](https://ollama.com/library/qwen3.5:9b-q4_K_M).
