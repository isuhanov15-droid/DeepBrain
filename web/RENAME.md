# Web 0.17.1 — Глубокий разум

Возвращено название навыка «Глубокий разум». Запуск: «Алиса, запусти навык Глубокий разум». В активном диалоге задавайте вопрос без дополнительного обращения. Команда «Алиса, хватит» завершает навык.

Новое название используется в приветствии, инструкции Qwen и Web. Старые обращения остаются совместимыми для памяти и протокола доставки. Содержимое сохранённых разговоров, факты, опыт, эмоциональные оценки и идентификаторы бесед не переписываются. Технические пути `/web/lada` и `/lada-face/v2/` сохранены для совместимости. Навык остаётся тем же приватным навыком Яндекса с прежней привязкой аккаунта.
